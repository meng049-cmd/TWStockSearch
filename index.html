如何更新與發布

本單檔版可直接開啟及匯入資料。 若需自動更新，還須安裝另附專案中的 GitHub Actions 更新腳本， 產生 data/stocks.json；單獨上傳此 HTML 不會自動抓取官方行情。 官方抓取目前尚未成功驗證。

網頁每 5 分鐘重新載入儲存庫資料；這不是盤中即時行情。 上櫃資料與社群文章目前須人工匯入。 其他官方入口可供核對，尚未接入自動篩選。

匯入 JSON 僅儲存在目前分頁，關閉或重新載入後還原。 若要永久更新，將 JSON 上傳到儲存庫 data/stocks.json。

資料僅供研究；請核對官方公告與資料日期。
