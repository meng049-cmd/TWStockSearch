# 台股投資研究面板

[開啟網站](https://meng049-cmd.github.io/TWStockSearch/)

專案僅包含以下功能：

- 上市／上櫃股票代號與名稱搜尋、可上下捲動的最近查詢記錄。
- 個股 K 線／收盤線圖、成交量、均線、布林、MACD、KD、RSI、OBV、外資與融資副圖。
- 日期觀察、量價與法人分析、手動買賣及研究註記、可選的均線交叉觀察標記。
- K 線固定於內視窗上半部，下半部八圖可獨立垂直捲動；各圖時間範圍同步。
- 個股重點儀表板呈現趨勢、量價、法人、動能與基本面摘要。
- 族群資金流向以同一張四象限氣泡圖呈現，每族群一點；橫軸為區間累計估算淨額，縱軸為截止日單日估算淨流速，圓面積按各日各法人估算淨額絕對值加總等比例縮放。支援1、3、5、10、20、30、60、90個交易日與截止日±切換。資金來源可複選外資、投信、自營商及「融資餘額」，合計後同步重算座標與面積。產業比較選單一次可選1～4個產業，以連續交易日氣泡、時間滑桿與可調速度自動播放觀察跨象限軌跡；象限只表示計算後位置，沒有獨立產業篩選。CSV隨目前模式與所選來源匯出。
- 主技術區依序為 K 線、成交量、外資、投信、自營商、MACD、KD、RSI 及可選指標圖。
- 搜尋旁的「台股大盤」以獨立視窗提供加權指數與官方法人資料，不改變所選股票。
- 搜尋前可依期交所官方普通股期貨標的名單篩選全部、有股票期貨或非股票期貨；ETF 不混入普通股篩選。名單過期或不可用時停用篩選。

## 結構

`index.html` 是唯一頁面。`assets/desk.js` 管理介面、圖表、查詢記錄與註記；純資料處理在 `assets/core.js`。技術指標與籌碼規則為獨立模組，圖表套件與授權位於 `assets/vendor/`。

`data/stocks.json` 提供上市目錄及近期官方行情，`data/history/` 依股票提供日歷史；`data/market-review.json` 提供官方大盤快照。`data/industry-flows.json` 由上市與上櫃個股每日法人淨買賣超按產業加總；金額以逐股淨買賣股數乘當日收盤價估算（元），各法人保留金額有效檔數。`assets/industry-bubbles.js` 處理區間與圓點比例，`assets/industry-flow-ui.js` 呈現圖表。上櫃目錄位於 `assets/otc-symbols.json`，個股行情由官方快照提供。

每小時同步大盤官方資料；股票期貨標的名單每四小時檢查。台灣交易日 18:30 排程更新盤後行情，法人與融資每四小時檢查並重建族群彙總。GitHub 排程可能延遲；介面明示實際資料日。來源失敗保留舊快照，缺值不當成零。

手動買賣與研究註記只儲存在瀏覽器；不代表券商成交。均線交叉標記不是買賣指令。個股淨額以張為單位，大盤法人資料以元為單位，不互相替代。

## 指標與分鐘買賣註記

可選指標庫提供 29 項常用技術指標，包含 KD、Stochastic RSI、CCI、DMI／ADX、MFI、CMF、VWAP、三種均線與通道等。可計算的週期參數可自行調整；這些是本站實作，並非 TradingView 完整授權產品或 Pine Script 引擎。

註記儲存台北日期／時間、成交價、買賣方向及建立時的週期；月／週／日顯示在對應 K 棒，同時標示價位線。點選本站 K 線可帶入時間與價位。註記可匯出 JSON，舊的日期註記仍保留，不猜測未知的分鐘。

GitHub Pages 未接入即時分鐘行情服務。若要在本站的分鐘 K 線精確標註，先匯入真實 OHLCV CSV：`datetime,open,high,low,close,volume`。`datetime` 採台北時間或明確 ISO 時區，成交量為股；資料僅保留於本次瀏覽。支援 1／3／5／15／30／60／120／240 分鐘彙整。未匯入時仍可保存精確成交註記，並使用 TradingView 外部圖表參考；本站不會將註記寫入跨來源 iframe。

## 上櫃與基本面資料

`sync_stock_metrics.py` 使用證交所及櫃買中心官方資料，另產生 `data/otc-stocks.json`、`data/otc-history/` 與 `data/stock-metrics.json`。上櫃首次補入最近約120日曆天的實際交易日 K 線，並補近25日曆天的法人、融資資料；後續更新時保留歷史。上市及上櫃目錄分開，不用交易所代碼猜測上櫃資料。

本益比只與同產業、同資料日且正本益比的其他公司比較（至少5家），低於中位數20%稱「同業相對偏低」，高於20%稱「同業相對偏高」。這不是內在價值估算；低本益比也可能反映景氣高峰、一次性盈餘或成長衰退。虧損／缺值／樣本不足時不判定低估。

當沖率使用官方逐股當沖成交股數÷同日總成交股數；不使用當沖資格名單或全市場比重當成個股數值。融資餘額與當日增減分開，均以張顯示。各項指標保留原始資料日期，來源失敗保留已驗證資料並記錄錯誤。

產業時間軌跡將「每顆氣泡累計區間」與「連續觀察日數」分開設定。例如累計5日、觀察20日，每個產業最多畫20顆日氣泡，各使用截至該日的5日資料。早期資料不足或中間缺值時不補零。歷史點只使用當時及之前資料。全市場快照以主導法人著色；軌跡以產業固定顏色著色，同一個焦點交易日發亮，沒有泡泡邊框與軌跡線。

融資原始單位為張，估算金額先乘1000轉為股再乘當日收盤價；缺marginChange時只有同筆資料同時提供實際餘額與前日餘額，才以兩者差額補入。融資是餘額變動市值訊號，與法人來源合計可能重疊。


所有選項即時套用。「確定」只捲動至完整圖表觀看區，「再次選擇」只返回選單最上層，保留當前選擇；觀看區將圖例、泡泡圖和時間軸放在同一視窗。快照時間軸切換觀察截止日，時間軌跡時間軸移動焦點交易日。



目前資金來源為外資、投信、自營商與融資餘額，可複選；融資不限制族群數，正負增減均納入。資金方向按餘額每日增減估算市值，實際餘額另以張數顯示。排行範圍與前十大介面已移除。

軌跡歷史氣泡保留2%～5%透明度，焦點日亮1000毫秒，再於450毫秒淡回。沒有任何泡泡邊框、hover邊框或軌跡線。自動播放從舊到新，速度為每交易日1.5、2、3、5秒，可暫停，末日自動停止；改選條件、手動時間軸或離開可見頁面會暫停。觀看區的確定／再次選擇只捲動畫面，保留播放與選項。
