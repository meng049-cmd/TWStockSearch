# TWStockSearch — 台股盤後資訊頁

官方來源版本：熱門族群 → 選取族群 → 條件篩選 → 股票報價與日 K 線。Facebook 與 PTT 已移除。

## 发布 GitHub Pages

將所有檔案合併至 `main`，到 **Settings → Pages → Source** 選 **GitHub Actions**。到 **Actions → Publish website** 手動執行發布；到 **Update official stock data** 可手動更新官方資料。工作流程也會每小時執行；首次須在 GitHub 啟用 Actions 並允許工作流程寫入儲存庫。

`index.html` 是單檔介面，但仍依賴 `data/stocks.json`、`data/themes.json`、更新腳本及 workflow；單獨上傳 HTML 不會取得即時資料。網頁有「複製網頁程式碼」與「下載本網頁」按鈕，這兩個功能只匯出介面，不包含資料與排程。

## 資料與更新

- 每小時取得證交所上市公司產業分類及公開資訊觀測站重大訊息；族群採官方產業分類，按最後交易日成交金額排序，不是社群熱度排名。
- 族群下列出官方分類、行情来源与实际取得的公司公告；点选公告可查看说明及其官方资料集链接。官方资料集不是每篇公告的专属链接。
- 官方重大訊息資料集不涵蓋全部新聞或歷史公告；從每次取得的公告累積近 30 日資料，不能保證每個族群都有新公告。
- 股票條件僅作用於選取族群的成員；未選族群時不列股票。週買量增加以前 5 個交易日為基期，對比最近 5 個交易日買進股數合計，非買賣超。
- 交易日台灣時間 18:30 更新證交所上市盘后行情。首次回補近 50 個日曆日；之後更新近 8 個日曆日。排程可能延遲，並非盤中即時報價。
- 顯示盤後收盤、漲跌幅、成交量及開高低；僅用實際取得的開高低收畫 K 棒，不補造歷史數據，不還原權息。可以連到官方行情入口核對。
- 目前不含上櫃股票。10 個官方入口中，實際串接的只有證交所行情／法人／產業分類與公開資訊觀測站重大訊息；其他入口僅供參考。
- 每筆資料顯示其來源與更新时间；來源或更新失败保留前次有效檔，GitHub Actions 中可查看错误原因。

## 已驗證

目前開發環境已實際取得 1,096 檔上市證券的歷史收盤、33 個產業族群與 6 則官方重大訊息；行情最近交易日為 2026-10-08。完整開高低收本次回補 4 個交易日；後續更新會繼續累積，較早歷史不畫假 K 棒。這不是對 GitHub 新部署後更新成功的承諾，發布後請查看 Actions 與頁面資料時間。

本機預覽：`python3 -m http.server 8000`。驗證：`node scripts/test_core.js`、`python3 -m unittest discover -s scripts -p 'test_*.py'`。實際更新：`python3 scripts/update_data.py`、`python3 scripts/sync_sources.py`。只使用 Python 標準函式庫，無需憑證或額外套件。
