# 第二版：盤後熱門股

第二版分支：`v2-afterhours-hotstocks`。第三版預留盤中資金速度，本版沒有實作或用日資料冒充盤中速度。

## 已實作

- 股票熱度：成交金額百分位 35%、相對成交量百分位 25%、發行股數週轉率百分位 20%、成交金額加速百分位 20%。
- 相對成交量：當日量除以前 20 個交易日均量，不含當日。
- 成交金額加速：最近 5 日平均金額，相較之前 20 日平均金額，兩段不重疊。
- 發行股數週轉率：當日成交股數除以公司資料中公布的已發行普通股數。不是自由流通股週轉率，股數參考日期與行情日期可能不同，表格提示列出日期。
- 百分位在最後交易日有完整資料的上市公司中計算，同值平均排名。缺少資料不排名；小樣本不補零。分數不是資金淨流入或獲利機率，也未經回測驗證。
- 族群分數：族群成交金額百分位 50% + 前 5 檔可排名成員平均熱度 50%；不足 5 檔取實際可排名成員。
- 先選熱門族群，再在其成員中按熱度、成交金額、相對量、週轉率或加速排序，套用原有均線與法人條件。
- 新增最低成交金額、熱度、相對量、週轉率及加速門檻。熱門門檻皆須符合；原有技術／法人條件可選全部或任一。
- 預設成交金額門檻 5,000 萬元。顯示門檻不改变市場原始排名；可選不限。
- 保留行情、至少五年日資料的 K 線、日／週／月、縮放與 TradingView 外部圖表。TradingView 內容仍由供應商控制，不作為排名資料來源。

## 五年歷史擴充（仍為第二版）

- 預設顯示五年，可選三年、一年、半年、三個月或全部；日資料聚合週線與月線，沿用縮放及歷史移動。新上市股票依實際歷史長度顯示，缺資料不補造。
- 首頁下載最近 30 個交易日的行情摘要；選股票後才載入其完整歷史 JSON，失敗可重試。分檔歷史也必須隨網站部署。
- 最低發行股數週轉率 1% 表示當日成交股數至少占已發行普通股數 1%；同一股可重複交易，不能解讀成換手股東比例。
- 最低成交金額加速 50% 表示近 5 日平均成交金額至少為前段 20 日平均的 1.5 倍。選 0% 仍要求不下降；選不限才不檢查此門檻。

## 股票期貨標的篩選

加入不限／有／無按鈕，套用於所選族群並可搭配原有條件。名單由期交所 SSFLists 每四小時更新；排除 ETF、合併同股的標準與小型契約。沒有有效名單時停用有／無按鈕。報價仍為股票行情。此功能屬第二版，不加入盤中資金速度。

## GitHub 操作：比較、發布與回退

1. 開啟儲存庫的 Code 頁面，點目前的分支名稱，在選單選 `v2-afterhours-hotstocks`，即可查看第二版檔案。不需下載 ZIP 或貼完整 HTML。
2. 開啟 `https://github.com/meng049-cmd/TWStockSearch/compare/main...v2-afterhours-hotstocks`。
3. 確認 base 為 `main`，compare 為 `v2-afterhours-hotstocks`，點 **Create pull request**。若已存在 PR，直接開啟它。
4. 核對修改內容後，點 **Merge pull request → Confirm merge**。這一步才把第二版切換成公開主站。暫時不要刪除第二版分支。
5. 到 **Actions** 查看 **Publish website** 最新執行綠勾。若沒有新執行，選 Publish website → Run workflow → 分支選 `main`。
6. 網頁部署成功後，開啟原網址 `https://meng049-cmd.github.io/TWStockSearch/`，強制重新整理，應看到 `V2`、熱度分數與新篩選門檻。
7. 到 **Actions → Update official stock data → Run workflow**，分支選 `main`，驗證第二版同步成功；後續每小時同步重大訊息並重算族群，公司基本資料每 4 小時更新，交易日 18:30 更新行情。請以工作流程紀錄及資料日期核對，排程可能延遲。

第二版分支上的手動工作流程只更新分支資料，不部署覆蓋主站；正式部署只允許 main。

如需回退，在已合併的 Pull request 頁面點 **Revert**，建立並合併回退 PR。不要直接強制推送或刪除 main。第一版另保留 `v1-before-hotstocks` 標籤供參考；查看標籤本身不會改變網站。

## 第三版規劃

先確認支援台股盤中的合法資料接口、延遲、費用及授權，再加入每分鐘成交金額、每分鐘量、短期加速與同時間歷史基準比較。盤中資料與盤後資料分開标示。TradingView 嵌入圖不是可直接取用的排行資料 API。
