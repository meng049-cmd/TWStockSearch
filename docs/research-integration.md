# TWStockSearch 整合研究工作區

由「市場選股」切換「轉折研究」，或在焦點個股、候選股清單與 K 線上按「研究」。兩個工作區共用選取標的及明暗主題。研究工作區以同網域的 `research/index.html` 載入，亦可直接開啟 `research/index.html?stock=2330`。

## 功能

- 日／週／月 K 線、成交量、法人、融資及技術指標共用時間軸，支援縮放、平移與十字線。
- KD、MACD、RSI、布林通道、OBV、ATR、ROC；資料暖機不足時不產生數值。
- 2～6 個標的以共同日期比較，價格指數以區間首個共同週期為 100。
- 每日盤後歸納、轉折事件、每日籌碼明細及研究筆記。
- CSV 預覽、合併匯入、匯出；期貨依契約月份和日夜盤分開，成交量為口。
- 筆記和匯入資料存於瀏覽器 IndexedDB；不支援時嘗試 localStorage。可匯出／還原 JSON 備份。它們不會提交到公開 GitHub，也不會同步原 Sites 的私人資料庫。

## 官方資料

股票讀取既有 `data/stocks.json` 與 `data/history/<code>.json`。原有 `foreignBuy`／`trustBuy` 是買進股數，仍供原選股條件使用，不能當成淨買賣超。

`scripts/sync_research.py` 另外取得最近 130 個市場交易日的 T86 淨買賣超與 MI_MARGN 融資餘額變化，新增 `foreignNet`、`trustNet`、`dealerNet`（股）及 `marginChange`（張）。研究介面把股票的成交股數和法人淨股數除以 1,000 換成張。外資口徑為不含外資自營商的外陸資淨買賣超加外資自營商淨買賣超。

期貨透過期交所 `DailyMarketReportFut` 累積 `data/research-futures.json`。歷史從成功取得的快照開始；較早區間用 CSV 匯入。不跨契約拼接，不把日資料當作分鐘資料。分鐘圖使用 TradingView 外部參考。

研究資料在來源程式更新時立即補抓，排程約每四小時檢查，和既有官方資料工作流程一起發布。`data/research-status.json` 保存來源警告；失敗時保留先前資料，缺少籌碼維持 null。頁面刷新只會重讀已發布快照，不會觸發官方爬取。

## 開發與驗證

靜態頁面不需要編譯。`node --test scripts/test-pages-data.cjs` 檢查資料轉換、個人儲存、合併與備份；`python -m unittest discover -s scripts -p test_research.py` 檢查官方欄位與單位解析。

`Publish website` 和 `Update official stock data` 兩個流程都必須複製 `index.html`、`data/`、`assets/`、`research/` 至發布目錄。原始 Sites 專案及託管資料庫不會因 GitHub 部署而變更。

視覺布局參考 shadcn/ui 官方 Dashboard Blocks 的側欄、指標卡、圖表與表格分層：https://ui.shadcn.com/blocks?category=dashboard 。實作保留靜態 HTML/JS 架構與既有資料排程。

## 結論、三日研判與個人規則

每日盤後定論只呈現一段歸納；證據區分成趨勢、量價、動能、外資、投信／自營商與融資，逐項列出明確判讀。外資、投信、自營商採最近5筆交易日淨買賣超；融資採同期間餘額增減與價格變化交叉判斷。

三日研判為固定規則模型：T+1較重視當日量價，T+3較重視趨勢、法人與槓桿。缺少資料不填零，減少可用面向並降低訊號一致度。同規則歷史回看只使用觀察日以前已完成的未來三日結果，至少30筆才顯示比例；該比例是樣本內描述，未經樣本外回測，不是預測勝率。若歷史中位數與規則方向相反，顯示「震盪觀察（規則與歷史分歧）」。價格未還原權息，除權息可能影響技術訊號。

每檔可設定最多8條個人規則，包括指標、比較方向、門檻、偏多／偏空及1～3分權重；有資料且符合門檻才計分。未啟用、未觸發與缺資料分開顯示。文字筆記本身不會被解讀成規則。個人規則儲存於瀏覽器，納入備份／還原，並會改變當日證據整合與三日方向。

首次補抓已取得2026-10-21盤後法人及融資，台積電與台化各130筆同日籌碼資料。之後以來源檢查時間、實際行情日期與逐日錯誤紀錄為準。


## 洗盤與換手結構研判

`research/chip-structure.js` 只使用觀察日及之前的 OHLCV、近五日法人淨額與融資增減。參考支撐取前日 MA20 與先前20筆低點較高者，容許1%偏離。量比不高於0.85視為量縮，達1.5視為顯著放量；這些是可稽核的模型門檻，不是已驗證的市場定律。

- 洗盤候選：先前有上升結構，回檔守支撐、量縮或下探後收復、近五日融資下降，且外資或三大法人合計仍有承接。放量跌破支撐且法人偏賣時，改列籌碼鬆動風險。
- 換手：區分放量承接、放量但方向待確認、賣壓型與未見明顯放量。收盤位置、上影線、法人淨額與融資配合用於描述強弱，法人淨額／成交量不能當成換手率。
- 洗盤／換手重用既有量價與籌碼，合計分數限制在±1；T+1／T+2／T+3權重分別為0.3／0.5／0.6，歷史回看套用同組規則且禁止使用未來資料。歷史比例仍為樣本內結果。
- 現有快照沒有流通股數與歷史持股分散，不能算真實換手率或證明持有人集中。集保戶股權分散表屬週資料，官方查詢：https://www.tdcc.com.tw/portal/zh/smWeb/qryStock 。目前只提供查詢連結，沒有聲稱已接入該資料。
- 資料不足不計分；期貨需要未平倉量與期貨法人部位，本功能不套用現股融資規則。

驗證涵蓋洗盤候選、去槓桿但不符洗盤、放量跌破、承接與賣壓型換手、槓桿擴張、一般量能、缺值、期貨排除與禁止前視偏誤。頁面測試確認兩張判讀卡與籌碼／走勢影響欄位。
