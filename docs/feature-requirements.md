# 最新功能需求與交付狀態

- 熱門族群排列於條件選股之前，公司基本資料每 4 小時、重大訊息全天每小時同步，列出各來源實際取得時間。
- Facebook、PTT 全部移除；僅保留官方資料與官方公告。
- 族群採證交所產業分類，熱度依最後交易日族群成交金額與成員活躍度綜合排序，並非社群聲量。
- 必須先選族群，才在其成員中篩選收盤站上 MA10／MA20、MA5 高於 MA10／MA20，以及外資／投信最近 5 日相較前 5 日買量增加至少 5%～30%。
- 股票列出收盤價、漲跌幅及成交量；點選股票顯示開高低收及真實日 K 線，提供官方行情入口。
- 未取得完整開高低收的日期不畫 K 棒；行情為盤後資料，非盤中即時報價。
- 網頁提供複製程式碼及下載 HTML 選項；無法下載時可由 GitHub 原始碼取得。
- 來源同步依賴 GitHub Actions、data/stocks.json、data/themes-v2.json、data/history/ 各股票歷史檔及 Python 更新腳本，不可只上傳 HTML 後宣稱自動同步完成。

詳細部署方式、資料來源與驗證結果見 README.md。

## 圖表擴充

回補至少五年官方日 K，支援日／週／月聚合、縮放與歷史移動。分鐘／小時圖經使用者選擇使用 TradingView 外部圖表，明確標示可能的延遲與使用限制；目前外部內容仍受環境網路政策阻擋而未驗證。熱門族群依最後交易日族群成交金額與成員活躍度綜合排序，不是社群聲量。

## 第二版股票期貨篩選（待官方來源驗證）

已加入不限／有股票期貨／無股票期貨按鈕、表格標記及四小時同步程式。來源目標為期交所 OpenAPI；目前雲端網路拒絕存取期交所，接口及實際欄位仍待官方回應核對。沒有有效名單時停用有／無選項，不將缺資料誤判為無。篩選仍作用於所選族群，報價與 K 線仍為股票資料。此變更位於 v2-stock-futures-filter 草稿分支，未合併主站。
