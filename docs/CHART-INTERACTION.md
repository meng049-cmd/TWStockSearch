# 圖表週期與互動

- 每日籌碼明細預設收合，按標題展開。
- 日／週／月使用私人資料庫行情，所有本站價量、動能及比較圖共用所選週期與日期範圍。週以週一分組，月以每月第一日分組；圖軸日期為期間起點，區間首尾只包含選定日期內實際交易日。OHLC 為首開、最高、最低、末收，量及籌碼為加總；任一籌碼缺值時整個期間該欄保留缺值。先前完整期間供指標暖機使用，首尾不完整期間會影響指標；不混入區間結束後資料。
- 十字線旁的文字為當日盤後解讀；週／月圖明確標記為期末實際交易日解讀，數字也對應該日，不冒充整週／整月結論。週／月指標採週／月單位，右側每日證據與觀察日仍採日資料。
- 分鐘／小時透過 TradingView 外部股票圖提供參考，可能延遲或受供應商限制。此圖不寫入資料庫，也不與本站日圖同步。固定期貨契約無驗證外部代碼時不嵌入替代契約。供應商顯示失敗時可用旁邊連結開啟查詢。
- 匯入結果提示在五秒後自動關閉，可手動關閉；連續匯入會重置計時。部分資料缺漏會明確顯示缺漏，不顯示完整成功。詳細補抓紀錄保留在進度區。

驗證：`node scripts/test-chart-ux.cjs`、`node scripts/test-chart-workspace.cjs`，以及既有 client、market、search、indicators、daily-summary、sync 測試。外部盤中資料供應與實際瀏覽器互動未由自動化瀏覽器驗證。
