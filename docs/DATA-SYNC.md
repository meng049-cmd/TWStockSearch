# 確認標的後的完整日期資料同步

- 搜尋結果的「確認標的並抓取匯入」直接啟動同步，不再先下載或再要求第二次確認。手動 CSV 下載／匯入仍保留。
- 股票整段日期按月查官方 OHLC／成交量，每批成功立即保存；不受整段 93 天上限限制。再檢查資料庫，將仍缺外資／投信／自營商／融資的已存交易日以每批 3 日補查，不再只查最後 20 筆。
- 再次確認會重查價量，籌碼只補查仍有缺漏的日期；相同標的／日期合併，未取得的欄位不覆蓋原有非空值。無資料、不適用不填零。
- 可看到價量批次、籌碼批次、實際價量起訖、外資與融資缺漏數及來源失敗內容。可重試或於目前批次完成後停止；已成功的批次保留。
- 套用日期與更新已存標的也沿用此流程；「補抓比較資料」可補查目前勾選的標的，完成後保留原觀察標的。
- 期貨歷史使用期交所 futDataDown 官方 POST CSV（Big5／UTF-8），分14天內小批，嚴格匹配商品代碼、到期月份與一般／盤後時段。未上市、到期後或休市不產生虛構 K 棒。期貨法人尚未接入，現股融資不適用。
- 已用官方 futDataDown POST 實際取得 2026-10-16 CSV，核對欄位及月份／時段；範例保存在 scripts/fixtures/taifex-20261016.csv 供解析回歸測試。資料源將來仍可能限流或未公布，網站會列為未完成，不以最新行情冒充整段歷史。
- 比較／指標下拉選單與均線勾選重新綁定新版圖表函式，避免跳回舊SVG或留下失效的圖表物件；比較區列出缺值或期貨適用限制。
