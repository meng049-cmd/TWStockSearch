第二版熱門股計算依據

熱門是交易活躍度，不代表資金淨流入或獲利機率。所有指標使用已完成交易日資料；盤中資金速度留在第三版。

股票熱度＝成交金額百分位 35%＋相對成交量百分位 25%＋發行股數週轉率百分位 20%＋成交金額加速百分位 20%。在完整指標的上市公司中每日重算，同值使用平均百分位；缺資料不排名。

相對成交量＝當日成交股數 ÷ 前 20 個交易日平均成交股數（不含當日）。發行股數週轉率＝當日成交股數 ÷ 官方目前公布的已發行普通股數 × 100%，不是自由流通股週轉率。股數與行情日期可能不同，資料日期可在股票列提示核對。

成交金額加速＝（最近 5 個交易日平均成交金額 ÷ 之前 20 個交易日平均成交金額 − 1）× 100%，兩段不重疊。族群熱度＝族群成交金額百分位 50%＋前 5 檔可排名成員平均熱度 50%。分數為透明的初版排序規則，未經回測驗證。

發布與同步說明

此 HTML 必須搭配 GitHub 更新腳本及工作流程。第二版熱門族群讀取 data/themes-v2.json，行情讀取 data/stocks.json；選取股票時才讀取 data/history/股票代號.json 的 5 年日資料。只有 HTML 不會自動產生文章或股票資料。

公司基本資料每 4 小時同步，重大訊息全天每小時同步；交易日台灣時間 18:30 排程更新行情。手動執行 GitHub 更新工作流程會立即更新全部來源。文章以股票代號對應產業，官方公告來源與內容可點選查看。熱門排序同時考量成交金額與成員活躍度，不代表社群聲量。

若某族群沒有新公告，仍顯示行情、官方分類與來源連結；不補造文章。排程可能延遲，請核對資料日期。
